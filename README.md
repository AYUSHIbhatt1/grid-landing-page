# Grid Landing Page

A responsive landing page built with **HTML and CSS** as a practice project for learning and applying CSS Grid, Flexbox, and responsive design.

## 🚀 What I Practiced

* CSS Grid
* Grid rows and columns
* Grid item spanning
* Flexbox
* Responsive layouts
* Media queries
* Responsive typography
* Font Awesome icons

## 🛠️ Technologies Used

* HTML5
* CSS3
* Font Awesome

## 📱 Responsive Design

The page is designed to work across different screen sizes, with a mobile layout using CSS media queries.

## 🎯 Purpose

This project was created to strengthen my understanding of **CSS Grid layouts** and practice building a responsive webpage from scratch.

## ✨ Features

* Responsive navigation
* CSS Grid-based hero section
* Statistics cards
* Responsive mobile layout
* Clean and minimal design
